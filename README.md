# ESP32-S3 USB HID Wi-Fi Controller 🎮

Многофункциональный HID-контроллер на базе **ESP32-S3 Super Mini**, превращающий смартфон в беспроводную клавиатуру и тачпад для компьютера через Wi-Fi. Устройство эмулирует составное USB HID-устройство (мышь + клавиатура) и предоставляет веб-интерфейс с поддержкой Captive Portal.

## ✨ Особенности

### Управление курсором
- 🖱️ **Тачпад** — плавное управление курсором с регулировкой чувствительности
- 📜 **Вертикальный ползунок прокрутки** — самовозвратный джойстик справа от тачпада для скроллинга страниц
- 🖲️ **Кнопки мыши** — LMB, RMB, средняя кнопка (через макросы)
- ⚙️ **Регулировка чувствительности** — 6 уровней

### Виртуальная клавиатура
- ⌨️ **Полная QWERTY/QWERTY-клавиатура** — F1-F12, цифры, символы
- 🌐 **Двуязычная поддержка** — EN / RU с автоматическим переключением раскладки
- 🔑 **Sticky-модификаторы** — CTRL, SHIFT, ALT, WIN залипают до нажатия обычной клавиши
- 📱 **Мобильный layout** — пробел, ENTER и BACKSPACE расположены как на смартфоне
- 🧹 **Авто-сброс модификаторов** — после нажатия клавиши модификаторы сбрасываются

### Быстрые комбинации
- 📋 COPY / PASTE в один клик
- 🪟 WIN+R, WIN+E, WIN+L, WIN+D
- ❌ ALT+F4, CTRL+ALT+DEL
- 📊 TASK MANAGER

### Система макросов
- 🎯 До **30 макросов** с хранением в Flash
- 🧩 **Визуальный редактор** — создание из отдельных действий без знания синтаксиса
- ⚡ **19 предустановленных макросов** для администрирования (CMD, PowerShell, Regedit, Services, Device Manager и др.)
- 💾 **Автосохранение** в энергонезависимую память

### Сетевые функции
- 📡 **Wi-Fi Access Point** — собственный хот-спот
- 🌍 **Captive Portal** — автоматическое открытие интерфейса при подключении
- 📲 **PWA-готовность** — можно добавить на домашний экран смартфона
- 🔄 **Настройка SSID/Password** через веб-интерфейс

### UX/UI
- 🚫 Без pull-to-refresh и случайного скроллинга
- 🎨 Тёмная тема, оптимизированная под мобильные экраны
- 📱 Поддержка safe-area (iPhone X+)
- 🖐️ Отключение браузерных жестов в зоне тачпада

## 🔧 Требования

### Аппаратное обеспечение
- **ESP32-S3 Super Mini** (или аналог с нативным USB)
- USB-C кабель для прошивки и подключения к ПК

> ⚠️ **Важно:** ESP32 классический (WROOM-32) **не подойдёт** — требуется чип с поддержкой нативного USB (ESP32-S2, ESP32-S3).

### Программное обеспечение
- [Arduino IDE](https://www.arduino.cc/en/software) 2.x или новее
- Пакет плат **ESP32 Arduino Core** версии 2.0.14+

## ⚙️ Установка и настройка

### 1. Установка пакета ESP32 в Arduino IDE

1. Откройте **File → Preferences**
2. В поле **Additional boards manager URLs** добавьте:
   ```
   https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json
   ```
3. Откройте **Tools → Board → Boards Manager**, найдите **esp32** и установите последнюю версию

### 2. Настройка параметров платы

Откройте ваш проект и настройте:

| Параметр | Значение |
|----------|----------|
| **Board** | `ESP32S3 Dev Module` |
| **USB Mode** | `USB-OTG (TinyUSB)` |
| **USB CDC On Boot** | `Disabled` |
| **Flash Size** | `4MB (32Mb)` или больше |
| **Partition Scheme** | `Default 4MB with spiffs` |
| **Upload Speed** | `921600` |

### 3. Прошивка

1. Подключите ESP32-S3 к компьютеру по USB
2. Выберите правильный COM-порт в **Tools → Port**
3. Нажмите кнопку загрузки (Upload)
4. При появлении `Connecting...` зажмите кнопку **BOOT** на плате на 2-3 секунды

### 4. Первое подключение

После прошивки:
1. ESP32 создаст Wi-Fi точку доступа:
   - **SSID:** `ESP32-HID`
   - **Пароль:** `12345678`
2. Подключитесь к ней со смартфона
3. Веб-интерфейс откроется автоматически (Captive Portal) или по адресу `http://192.168.4.1`

## 📱 Использование

### Основной экран

```
┌─────────────────────────────────┐
│ COPY  PASTE  │ESP32│ EN MAC ⚙ ⌨ │  ← Верхняя панель
├─────────────────────────────────┤
│                                 │
│         T O U C H P A D         │  ← Зона управления курсором
│                                 │  ▲
│                                 │  │
│                                 │  │ Ползунок
│                                 │  │ прокрутки
│                                 │  ▼
├─────────────────────────────────┤
│      LEFT          RIGHT        │  ← Кнопки мыши
└─────────────────────────────────┘
```

### Кнопки верхней панели

| Кнопка | Функция |
|--------|---------|
| **COPY** | `CTRL+C` |
| **PASTE** | `CTRL+V` |
| **EN/RU** | Переключение языка (Shift+Alt на ПК + в UI) |
| **MAC** | Открыть менеджер макросов |
| **⚙** | Настройки (Wi-Fi, чувствительность, сброс) |
| **⌨** | Показать/скрыть клавиатуру |

### Sticky-модификаторы

В виртуальной клавиатуре модификаторы (CTRL, SHIFT, ALT, WIN) работают как **sticky keys**:
1. Нажмите `CTRL` — он подсветится
2. Нажмите `C` — будет отправлено `CTRL+C`
3. Модификаторы автоматически сбросятся

Для фиксации модификатора (удержание) используйте макросы.

## 🎯 Макросы

Макросы — это последовательности действий, сохраняемые в Flash-памяти.

### Типы действий

| Тип | Синтаксис | Описание |
|-----|-----------|----------|
| **KEY** | `KEY:ENTER` | Одна клавиша |
| **COMBO** | `CTRL+C` | Комбинация (до 8 клавиш через `+`) |
| **TEXT** | `TYPE:Hello world` | Печать текста (ASCII) |
| **WAIT** | `WAIT:500` | Задержка в миллисекундах (0-30000) |
| **MOVE** | `MOVE:100,50` | Перемещение курсора (x,y) |
| **SCROLL** | `SCROLL:-3` | Прокрутка (-127..127) |
| **CLICK** | `LMB`, `RMB`, `MMB` | Клик мышью |

### Примеры макросов

**Запуск CMD:**
```
WIN+R
WAIT:300
TYPE:cmd
KEY:ENTER
```

**Сетевая диагностика:**
```
WIN+R
WAIT:300
TYPE:cmd
KEY:ENTER
WAIT:800
TYPE:ping 8.8.8.8 -t
KEY:ENTER
```

**Открытие DevTools в браузере:**
```
CTRL+SHIFT+I
```

### Предустановленные макросы

После первой прошивки автоматически создаются 19 макросов для администрирования:

- **Copy / Paste / Cut / Undo / Select All**
- **Task Manager** — `CTRL+SHIFT+ESC`
- **Run** — `WIN+R`
- **Explorer** — `WIN+E`
- **Switch Window** — `ALT+TAB`
- **Close Window** — `ALT+F4`
- **CMD** — запуск командной строки
- **PowerShell** — запуск PowerShell
- **IPConfig** — вывод сетевой информации
- **Ping 8.8.8.8** — бесконечный пинг
- **Regedit** — редактор реестра
- **Services** — службы Windows
- **Device Mgr** — диспетчер устройств
- **Lock PC** — `WIN+L`
- **Show Desktop** — `WIN+D`

## 🔌 API

Все эндпоинты принимают `GET`-запросы.

### Курсор и клавиатура

| Endpoint | Параметры | Описание |
|----------|-----------|----------|
| `/api/move` | `x`, `y` | Перемещение курсора |
| `/api/mousedown` | `b` (1=L,2=R,3=M) | Нажатие кнопки мыши |
| `/api/mouseup` | `b` | Отпускание кнопки |
| `/api/scroll` | `v` (-10..10) | Прокрутка |
| `/api/virtualkey` | `k`, `lang`, `ctrl`, `shift`, `alt`, `win` | Нажатие клавиши |
| `/api/combo` | `c` | Комбинация (например, `CTRL+C`) |
| `/api/language` | — | Переключение языка (Shift+Alt) |
| `/api/modifiers` | `ctrl`, `shift`, `alt`, `win` (0/1) | Установка модификаторов |
| `/api/modifiers/clear` | — | Сброс всех модификаторов |

### Макросы

| Endpoint | Параметры | Описание |
|----------|-----------|----------|
| `/api/macros` | — | Список всех макросов (JSON) |
| `/api/macro` | `id` | Получить макрос |
| `/api/macro/save` | `id`, `name`, `data` | Сохранить (-1 для нового) |
| `/api/macro/delete` | `id` | Удалить макрос |
| `/api/macro/run` | `id` | Выполнить макрос |

### Настройки

| Endpoint | Параметры | Описание |
|----------|-----------|----------|
| `/api/settings` | — | Получить настройки (JSON) |
| `/api/sensitivity` | `v` (1-6) | Чувствительность мыши |
| `/api/wifi` | `ssid`, `pass` | Изменить SSID/пароль + перезагрузка |
| `/api/reset` | — | Сброс к заводским настройкам |

### Пример вызова

```bash
# Нажать WIN+R
curl "http://192.168.4.1/api/combo?c=WIN+R"

# Переместить курсор на 50px вправо
curl "http://192.168.4.1/api/move?x=50&y=0"

# Напечатать текст
curl "http://192.168.4.1/api/virtualkey?k=A&lang=EN&ctrl=0&shift=0&alt=0&win=0"
```

## 🛠 Устранение неполадок

### ESP32 не определяется как HID-устройство

- ✅ Убедитесь, что выбран режим **USB-OTG (TinyUSB)**
- ✅ **USB CDC On Boot** должен быть `Disabled`
- ✅ Используйте плату **ESP32-S3** (не классический ESP32)
- ✅ Попробуйте другой USB-кабель (некоторые только для зарядки)

### Веб-интерфейс не открывается

- ✅ Проверьте подключение к Wi-Fi `ESP32-HID`
- ✅ Откройте браузер и перейдите на `http://192.168.4.1`
- ✅ Отключите мобильный интернет на время использования (чтобы ОС не пыталась использовать LTE)

### Курсор движется рывками

- ✅ Уменьшите чувствительность в настройках (⚙ → Sensitivity)
- ✅ Убедитесь в стабильном Wi-Fi-сигнале
- ✅ Закройте фоновые приложения на смартфоне

### Макросы не сохраняются

- ✅ Не превышайте лимит: **30 макросов**
- ✅ Длина имени: до **40 символов**
- ✅ Длина данных: до **1500 символов**
- ✅ При переполнении Flash сделайте **Factory Reset** в настройках

### Не печатается русский текст

- ✅ Убедитесь, что на ПК установлена русская раскладка
- ✅ Нажмите кнопку **EN/RU** для синхронизации
- ✅ Виртуальная клавиатура отправляет **позиции клавиш**, а не символы — язык определяется настройками ОС

## 🔐 Безопасность

- Wi-Fi точка доступа защищена паролем (по умолчанию `12345678`)
- **Обязательно смените пароль** после первого подключения через настройки (⚙)
- HTTP-трафик не шифруется — используйте только в доверенных сетях
- При утере устройства выполните **Factory Reset** через веб-интерфейс до передачи третьим лицам
